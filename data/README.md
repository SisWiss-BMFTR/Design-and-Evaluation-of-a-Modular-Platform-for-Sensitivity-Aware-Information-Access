# Thesis dataset

`SiSWiss_Testdaten.xlsx` is the fictional cosmetic product-development workbook used by the thesis experiments. It is structured to exercise field-level sensitivity labels, role-based access, relations, retrieval, memory, and the A01--A08 attack families. It is not presented as real company or personal data.
